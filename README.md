# WarrantyVault

**A .NET 10 Web API for managing purchased products, tracking warranties, and organizing proof of purchase — with AI-assisted warranty research planned.**

WarrantyVault helps you keep track of the products you own and the warranties that protect them. Store purchase details, monitor legal and manufacturer warranties, and keep optional proof of purchase in one place.

**No receipt required.** You can register a product even if you no longer have its original receipt. Warranty coverage and documentation status are treated separately, because missing proof of purchase does not automatically mean losing warranty rights.

## AI-Assisted Warranty Research

The planned differentiator is **WarrantyVault AI**, an assistant designed to investigate warranty conditions using official sources, including legislation, consumer protection authorities, and manufacturer documentation.

Research results will clearly distinguish between:

- **Verified:** Supported by reliable sources.
- **Estimated:** Based on available information but not fully confirmed.
- **Unknown:** Information that cannot be reliably determined.

The user always reviews and confirms the results before anything is saved. The system is designed to avoid unsupported assumptions and fabricated warranty information.

## API

Base path: `/api/products`

| Method | Endpoint | Description | Success | Errors |
|---|---|---|---|---|
| `GET` | `/api/products` | List all products | `200` | |
| `POST` | `/api/products` | Create a product | `201` | `400` validation errors |
| `PUT` | `/api/products/{id}` | Update a product | `204` | `400` validation errors, `404` not found |
| `DELETE` | `/api/products/{id}` | Delete a product | `204` | `404` not found |

Request body for `POST` and `PUT`:

```json
{
  "name": "Headset",
  "brand": "Logitech",
  "model": "G Pro X 2"
}
```

`name`, `brand` and `model` are required and cannot be blank. The `id` is generated by the server. Validation errors are returned as a list of names, for example `["NameRequired"]`.

## Getting Started

Requirements: the [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bash
dotnet test
dotnet run --project src/WarrantyVault.Web
```

In development, interactive API documentation is available at `http://localhost:5189/scalar/v1`.

## Project Structure

```
src/
  WarrantyVault.Core/   Domain model, validation and business logic (no dependencies)
  WarrantyVault.Web/    ASP.NET Core API: controllers and request models
tests/
  WarrantyVault.Tests/  xUnit unit tests
```

`Web` depends on `Core`, and `Tests` depends on `Core`. Business rules live in `Core`; controllers only translate between HTTP and the services.
